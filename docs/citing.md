## Licenses

The package is MIT-licensed. The pretrained checkpoints carry their own
licenses, several of which are non-commercial, and
{data}`lazy.CHECKPOINTS <lazy.models.CHECKPOINTS>` quotes each one. So, please check the license of the checkpoint you are using before applying it to your own work.
