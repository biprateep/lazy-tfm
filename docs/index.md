# LAZY: Lazy but Accurate Z\* for Yinz

<small>\*Where Z is any quantity you may want to predict, such as galaxy
redshift, metallicity, atomic number, electrical impedance, or whatever you
want (Z stands for [many
things](https://en.wikipedia.org/wiki/Z#Other_uses)).</small>

LAZY is a Python package that provides a unified wrapper around several
pretrained [tabular foundation models](tfm) (TabPFN, TabICL, TabFM and
LimiX-2), so that the user does not have to bother with the nuances of each
one. We standardize their interface, defaults and outputs behind one API,
which is similar to and compatible with scikit-learn's, and LAZY returns the
full probability distribution of the target for every model rather than a
single value.

## Getting Started

### Installation

LAZY is on PyPI as `lazy-tfm` and is imported as `lazy`. To install it with
every supported model:

```console
pip install 'lazy-tfm[all]'
```

With [uv](https://docs.astral.sh/uv/), use `uv add 'lazy-tfm[all]'` in a
project or `uv pip install 'lazy-tfm[all]'` in an environment. For detailed
installation instructions, including support for specific models, check out
the {doc}`installation` page.

### Usage

As a quick demonstration, we fill in the missing parts of a noisy curve.
{func}`~lazy.datasets.make_chirp` generates a sinusoid whose amplitude and
frequency both grow with $x$, adds Gaussian noise to it and deletes three
chunks of the data, which become the test set. We then give the remaining
points to TabPFN-3.5 as its training data and predict the mean and the central
68% interval of $y$ in each gap. For clarity, we write out every
hyperparameter at its default value, so `lazy.LazyModel()` gives the same
model. TabPFN-3.5 is best run on a GPU, though a context this small also runs
on a CPU (see {doc}`installation`).

```python
import lazy
from lazy import datasets

X_train, X_test, y_train, y_test = datasets.make_chirp(random_state=0)

model = lazy.LazyModel(
    "tabpfn",
    version="v3.5",
    n_estimators=8,
    transforms="auto",
    feature_shuffle=True,
    bag_size=None,
    kv_cache=True,
    y_grid=None,
    device="auto",
    random_state=0,
    chunk_size=8192,
    softmax_temperature="auto",
    mixed_precision=True,
    outlier_threshold="auto",
)
model.fit(X_train, y_train)

y_mean = model.predict(X_test, method="mean")
y_low, y_high = model.predict_interval(X_test, coverage=0.68).T
```

```{figure} figures/figs/chirp_demo.png
:alt: A noisy chirp with three gaps, filled by TabPFN-3.5's mean and 68% interval.
:width: 100%

The noisy chirp generated by `make_chirp` and TabPFN-3.5's predictions in the
three gaps. The blue line shows the training data, the gray dashed line the
true curve in the gaps, the orange points the mean of each predicted
distribution and the orange band its central 68% interval. We observe that the
mean tracks the true curve in each gap, most closely in the first two, and
that the true curve lies within the 68% interval everywhere in the three gaps
(the interval describes the noisy targets, so it is wider than the uncertainty
on the curve itself).
```

The model was never trained on this curve. `fit` stores the training rows
(and, with the key/value cache on, the network's encoding of them), and the
predictions come from forward passes of the pretrained network over them, one
per ensemble member, with no weights updated. The code that makes this figure
is in
[`docs/figures/make_figures.py`](https://github.com/biprateep/lazy-tfm/blob/main/docs/figures/make_figures.py).
